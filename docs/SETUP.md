# セットアップガイド

## 1. インストール

1. [Releases](https://github.com/utausnskareshi/movie-creator-studio/releases) から最新の `Movie-Creator-Studio-Setup-x.x.x.exe` をダウンロードします。
2. 実行します。**「WindowsによってPCが保護されました」(SmartScreen)** が表示された場合は、「詳細情報」→「実行」をクリックしてください(本アプリは現在コード署名を行っていないため表示されます。インストーラーはGitHub Actionsでソースからビルドされ、GitHub Releasesから配信されます)。
3. インストール先を選んで完了します。

## 2. 初回セットアップ(アプリ内ウィザード)

アプリ起動後、サイドバーの「セットアップ」からウィザードを進めます。

### ① 環境診断
GPU(`nvidia-smi`)・システムRAM・ディスク空き容量を自動検出します。

| VRAM | 推奨 |
|---|---|
| 24GB | 全モデル快適。既定設定のままでOK |
| 16GB | 全モデル動作可。720pは時間がかかる場合あり |
| 12GB | Wan2.2 5B / Cosmos 2B / CogVideoX 推奨 |
| 8GB | Wan2.2 TI2V-5B のみ推奨 |

### ② インストール先
エンジン・モデル・生成動画の保存先です。既定は `C:\MCS-Data`。**パスは短い場所を推奨**(Windowsの260文字パス制限対策)。モデルは非常に大きいため、空き容量の多いドライブを選んでください。

### ③ エンジンとツール
- **ComfyUI**(約2GBダウンロード / 展開後約7GB): 動作検証済みバージョンに固定して導入されます
- **ffmpeg**(約150MB): 編集・書き出しに使用します

いずれも公式配布元(GitHub Releases)から直接ダウンロードし、SHA256で検証します。

### ④ モデルのダウンロード
使いたいモデルのカードで「ダウンロード」→ ライセンス確認 → 同意して開始。

| モデル | 容量目安 | 用途 |
|---|---|---|
| AnimeGen | 約118GB(Wan2.2と共有分含む) | アニメ・イラストを動かす |
| Wan2.2 A14B | 約65GB | シネマティック映像 |
| Wan2.2 TI2V-5B | 約18GB | 軽量・低VRAM環境向け |
| HunyuanVideo 1.5 | 約56GB | 激しい動き・物理表現 |
| CogVideoX-5B-I2V | 約17GB | キャラ画像を動かす |
| Cosmos Predict2 2B | 約13GB | 空撮・背景映像 |

- ダウンロードは中断しても**レジューム(続きから再開)**できます
- 共有ファイル(テキストエンコーダ等)は自動で重複排除されます
- 回線状況により数十分〜数時間かかります

## 3. はじめての生成

1. ホーム画面の「やりたいことから選ぶ」で画面を選択
2. プロンプトを入力(日本語チップで組み立て可能)し、「生成開始」
3. 進捗は画面下部の生成キューに表示されます(プレビュー付き)
4. 完了すると「ライブラリ」に自動登録されます

> 💡 最初は **Wan2.2 の高速モード(4ステップ)** か **Cosmos 2B** が短時間で結果が見えるのでおすすめです。

## 4. トラブルシューティング

| 症状 | 対処 |
|---|---|
| エンジンが起動しない | 設定フォルダ(`%APPDATA%\movie-creator-studio\logs\comfyui.log`)を確認。GPUドライバを最新に |
| VRAM不足(OOM)エラー | 解像度・フレーム数を下げる。他のGPU使用アプリを終了。モデル切替直後は自動でVRAM解放されます |
| ダウンロードが失敗する | 自動リトライされます。プロキシ環境では設定画面のHFミラーを検討 |
| 生成が非常に遅い | 高速モード(lightning / 蒸留版)を使用。初回はモデルロードに数分かかります |

## 5. アンインストール

1. Windowsの「設定 > アプリ > インストールされているアプリ」から Movie Creator Studio をアンインストール
2. 途中の確認ダイアログで削除範囲を選べます:
   - **「はい」= 完全削除** — ダウンロードしたモデル・生成した動画・設定(データフォルダと `%APPDATA%\movie-creator-studio`)をすべて削除し、インストール前の状態に戻します
   - **「いいえ」= アプリ本体のみ削除** — データは残ります(再インストールすればそのまま使えます)
3. 「いいえ」を選んで後からデータだけ消す場合は、データフォルダ(既定 `C:\MCS-Data`)と `%APPDATA%\movie-creator-studio` を手動で削除してください

※ 完全削除は、データフォルダ内でアプリが作成したサブフォルダ(engine / models / ffmpeg / llm / work / library / exports)だけを対象にします。ご自身で同じフォルダに置いたファイルは削除されません。
